# Operating Systems - Core Concepts

## 1. Introduction to Operating System
- Software that manages hardware and software resources
- Acts as an intermediary between computer programs and computer hardware
- First program loaded when computer starts (after firmware)

## 2. What is an Operating System
- Resource manager for computer systems
- Provides interface between user and hardware
- Controls execution of programs
- Manages memory allocation
- Handles input/output operations

## 3. Types of Operating Systems

### a) Batch Operating System
- Similar jobs grouped together
- No direct interaction between user and computer

### b) Multi-Programming OS
- Multiple programs run simultaneously
- CPU utilization optimized

### c) Multi-Tasking OS
- Multiple tasks executed concurrently
- Examples: Windows, macOS, Linux

### d) Real-Time OS
- Time-critical operations
- Used in scientific equipment and industrial control

### e) Distributed OS
- Manages networked computers
- Appears as single system to users

## 4. Functions of Operating System

### Process Management
- Creation and deletion of processes
- Scheduling of processes
- Process synchronization

### Memory Management
- Allocation and deallocation
- Virtual memory management
- Memory protection

### File Management
- File creation and deletion
- Directory management
- File security

### Device Management
- Device driver management
- Device allocation
- Buffer management

## 5. Goals of Operating System

### Primary Goals
- Convenience: Make computer user-friendly
- Efficiency: Maximize resource utilization
- Ability to evolve: Adapt to new features/requirements

### Secondary Goals
- Error detection and handling
- Protection and security
- Resource accounting
