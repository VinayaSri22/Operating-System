# Operating System Services

## User Services

### 1. User Interface (UI)
- Command-Line Interface (CLI)
- Graphical User Interface (GUI)
- Batch Interface
  - A batch interface is a type of operating system interface where multiple jobs are grouped together and executed sequentially without direct user interaction, using Job Control Language (JCL) to specify all necessary instructions and resource requirements up front.

### 2. Program Execution
- Loads program into memory
- Runs the program
- Terminates execution (normal/abnormal)

### 3. I/O Operations
- Manages input/output devices
- Buffers data
- Handles device drivers

### 4. File System Manipulation
- Create/Delete files
- Create/Delete directories
- File operations: read, write, append
- File searching
- List file information
- Permission management

### 5. Communications
- Process-to-process communication
- Inter-process communication (IPC)
- Network communication

## System Services

### 6. Error Detection
- Hardware errors (CPU, memory, I/O devices)
- Software errors
- Provides appropriate response
- Debug information

### 7. Resource Allocation
- CPU scheduling
- Memory management
- Device management
- Storage space allocation

### 8. Accounting
- Track user time and resource usage
- Monitor system performance
- Usage statistics
- Billing users (in some systems)

### 9. Protection and Security
- File access control
- System resource access control
- Authentication
- Authorization
- Encryption servicest
